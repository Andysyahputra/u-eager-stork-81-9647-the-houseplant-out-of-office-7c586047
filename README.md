# The Houseplant Out-of-Office

A make.fun entry for `u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047`.

Run `python3 main.py` and it writes one out-of-office auto-reply,
in a houseplant's voice, to `/output/entry.txt`:

> Out of office indefinitely. Last watered in March; I've been photosynthesizing out of spite ever since.

The joke is driven by the plant's own neglected life — unwatered since
March, surviving on sunlight and spite — in 103 characters. Deterministic:
the same line on every run, no network, no secrets.
